# Plant 端口速查

Plant 是 Cimulink 对游戏内方块能力的封装。每个 Plant 会把方块的可控量暴露成输入端口，把可观测量暴露成输出端口。输入端口通常由 Cimulink 信号驱动，输出端口通常在每个更新阶段从方块状态中采样。

本文档覆盖当前源码中的所有 Plant 子类端口。没有固定端口的基类会在开头说明。

## 基类与代理

| 类 | 说明 |
| --- | --- |
| `Plant` | Plant 抽象基类，不直接声明端口。 |
| `MutablePlant` | 可动态调整组件生命周期的 Plant 基类，不直接声明端口。 |
| `MainThreadPlant` | 需要回到主线程安全访问方块的 Plant 基类，不直接声明端口。 |
| `PlantProxy` | 不是 Plant 子类，但常与 Plant 一起使用。它把某个 `NamedComponent` 的指定端口代理出来。默认代理端口通常最多包含前 8 个输入和前 8 个输出，可在代理端口界面中启用或关闭。 |

## 动态伺服电机：`MotorPlant`

对应动态电机类方块。

### 输入端口

| 端口 | 含义 |
| --- | --- |
| `target` | 控制目标。具体含义跟当前电机控制模式一致，通常是目标角度/目标值。 |
| `lock` | 锁定信号。大于 `0.5` 时锁定，小于等于 `0.5` 时解除锁定。 |
| `torque` | 输出扭矩限制/指令，写入电机的输出扭矩。 |

### 输出端口

| 端口 | 含义 |
| --- | --- |
| `current` | 当前控制器反馈值。 |
| `angle` | 当前伺服角度。 |
| `omega` | 当前伺服角速度。 |

## 动态滑轨：`SliderPlant`

对应动态滑轨类方块。

### 输入端口

| 端口 | 含义 |
| --- | --- |
| `deploy` | 目标伸出量/控制目标。 |
| `lock` | 锁定信号。大于 `0.5` 时锁定，小于等于 `0.5` 时解除锁定。 |
| `force` | 输出力限制/指令，写入滑轨的输出力。 |

### 输出端口

| 端口 | 含义 |
| --- | --- |
| `current` | 当前控制器反馈值。 |
| `distance` | 当前滑轨距离/伸出量。 |

## 摄像机：`CameraPlant`

对应摄像机类方块。摄像机 Plant 同时提供命中/视角采样和摄像机控制输入。

### 输入端口

| 端口 | 含义 |
| --- | --- |
| `clipNewBlock` | 触发一次方块射线选取。建议使用 `0 -> 1` 脉冲。 |
| `clipNewEntity` | 触发一次实体射线选取。建议使用 `0 -> 1` 脉冲。 |
| `clipNewShip` | 触发一次船/物理对象射线选取。建议使用 `0 -> 1` 脉冲。 |
| `clipNewPlayer` | 触发一次玩家射线选取。建议使用 `0 -> 1` 脉冲。 |
| `set_pitch` | 设置摄像机俯仰角。 |
| `set_yaw` | 设置摄像机偏航角。 |

### 输出端口

| 端口 | 含义 |
| --- | --- |
| `latest_x` | 最近一次选取结果的位置 X。 |
| `latest_y` | 最近一次选取结果的位置 Y。 |
| `latest_z` | 最近一次选取结果的位置 Z。 |
| `latest_vx` | 最近一次选取结果的速度 X。 |
| `latest_vy` | 最近一次选取结果的速度 Y。 |
| `latest_vz` | 最近一次选取结果的速度 Z。 |
| `yaw` | 摄像机当前本地偏航角。 |
| `pitch` | 摄像机当前本地俯仰角。 |
| `abs_yaw` | 摄像机当前绝对偏航角。 |
| `abs_pitch` | 摄像机当前绝对俯仰角。 |
| `abs_view_x` | 摄像机绝对视线方向 X。 |
| `abs_view_y` | 摄像机绝对视线方向 Y。 |
| `abs_view_z` | 摄像机绝对视线方向 Z。 |
| `used` | 摄像机是否正在被使用。使用中为 `1`，否则为 `0`。 |
