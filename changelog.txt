Control Craft Changelog
2.24.4 - 2026-03-21
====================
- Expanded computer Lua with player data access, client-to-server `Network.send`, server-side network reads, configurable screen resolution/surface size/offset, and clearer error logging.
- Improved Lua script bootstrap by loading bundled `luaml.lua` before resource reloads complete and centralizing Lua error sanitization.
- Reworked compact flaps into transformable bearings with corrected placement/rotation center behavior, safer disassembly reset, and wider tracking/no-cull support.
- Bumped ShaoLib to 1.5.0 and switched fast clip integration to the new `LodRaycastAPI`.
- Moved local `libs:` dependency versions into `gradle.properties`.

2.24.2 - 2026-03-17
====================
- Added a zh-CN Lua links usage guide for computer blocks.
- Added `ComputerDisplayMetrics` and a Lua `Block` library (`front/left/up` in local and world space).
- Added compact flap model variants (`n/p` x `u/m/d`) and client render offset/axis updates for flap rendering.
- Added jet rudder flame model + texture for translucent exhaust rendering.
